

### **Role-Based Access Sheet**

| Role | Feature / Page | Details & Permissions |
| :---- | :---- | :---- |
| **Traveller** | Discover Accommodation | Search bar and Discover accommodation page |
| **Traveller** | Spontaneous Escapes | Spontaneous escapes page (client view) |
| **Traveller** | Share the Love | Share the love page (get points for refferals) |
| **Traveller** | Profile | Profile page \- Bookings history page |
| **Traveller** | Points | Points page \- Points for refferals wich they can trade for rewards |
| **Host** | Landing Page | Landing page creation feature |
| **Host** | Bookings | Table view for their own booking by unit |
| **Host** | Spontaneous Escapes | Spontaneous escapes page (host view) \- select and apply discounts for certain nights |
| **Host** | Analytics | Analytics page \- simple page with analytics from the landing page \- number of views, customer inflow by refferal, customer segmented data |
| **General Admin** | Host Management | Table for every "host" user, with search and "suspend" permissions |
| **General Admin** | Landing Page Management | Table for every landing page and "delete" permission |
